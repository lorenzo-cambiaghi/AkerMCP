FluidR3 General MIDI SoundFont — licence
========================================

AkerMCP does not contain this SoundFont. `create_music` with "engine": "soundfont"
downloads it on first use to a per-user cache, and this notice travels with it because
that is the one condition the licence asks for. Nothing obliges you to use this font:
AKER_MCP_SOUNDFONT points the tool at any .sf2 you prefer.

The licence covers redistributing the SoundFont or a derived sound library. It does not
cover recordings made with it, so audio that create_music generates for your project
carries no obligation from this file.

The file this tool fetches
--------------------------

FluidR3 GM+GS, 151,001,312 bytes,
SHA-256 545B2833936F15F04DF5F0C5C4096B3BA6CED46EC7031F61991CAE46F8681986

The download is rejected unless it matches that hash, so a mirror cannot serve
something else in its place.
